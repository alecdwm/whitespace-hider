# Privacy policy

Effective 27 October 2026.

Whitespace Hider for GitHub doesn't collect, store or share any data about you.

## What the extension does

The Safari extension runs only on pages at `https://github.com`. On those pages it reads the
page's URL and the links on the page. When a URL or link points to a pull request's "Files
changed" view and doesn't set `w`, the extension adds `w=1` to it. This happens inside Safari on
your device.

The extension:

- doesn't send anything to the developer or to any third party
- doesn't make network requests of its own; reloading a diff page with `w=1` is an ordinary
  request to GitHub, like clicking a link
- doesn't read page content other than URLs and links
- doesn't store anything on your device

## The app

The Whitespace Hider for GitHub app only shows how to turn the extension on. It has no
accounts, analytics, advertising or tracking, and it doesn't connect to the network.

## GitHub

Your use of GitHub is covered by
[GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
